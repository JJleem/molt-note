cpal 0.18.2의 API 중 **컴파일로 확인한 것** (§14.3에도 ADR에도 서명 수준의 기록이 없어
이 저장소가 직접 확인했다):

    cpal::default_host()                → Host
    HostTrait::default_input_device()   → Option<Device>
    HostTrait::input_devices()          → Result<_, cpal::Error>  (Device iterator)
    DeviceTrait::description()          → Result<DeviceDescription, cpal::Error>
    DeviceDescription::name()           → &str
    DeviceTrait::id()                   → Result<DeviceId, cpal::Error>   (쓰지 않았다)

  주의: 0.18.2의 장치 이름은 `Device::name()`이 아니라 `description().name()`이다.
  이것은 컴파일러 오류로 확인한 사실이며 추정이 아니다.

  `DeviceId`는 선택 키로 쓰지 않았다 — 앱 실행 사이에서 안정적인지 UNVERIFIED이기 때문이다.

**컴파일은 "장치가 열린다"는 뜻이 아니다.** 실제 열거 결과 · macOS TCC 프롬프트 ·
열거된 이름과 물리 마이크의 대응은 사람이 확인한다 (ADR-0003 §12). 이 Task는 그것을
확인하지 않았고 확인했다고 적지도 않았다.
