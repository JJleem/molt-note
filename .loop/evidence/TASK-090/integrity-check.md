## 이 Run에서 실행할 수 없었던 것 — 정직하게 적는다

Runtime이 이 Run에 허용한 명령은 `node tools/loop-runtime/loopctl.mjs self-check` 하나다.
**`git diff` · `git status` 는 거부됐다.**

```text
$ git diff -U0 -- docs/PHASE-3-TRANSCRIPTION-SMOKE-TEST.md
This Bash command contains multiple operations. The following part requires approval: git diff ...
```

그러므로 아래 확인은 **`grep` 기반의 구조 확인**이며, 삭제 줄 대조(`git diff` 의 `-` 줄)는
Verifier가 직접 수행해야 한다. 이 Run이 대신 수행했다고 적지 않는다.

## 이 Run이 사용한 편집 수단

`Edit` 도구 5회 · `Write` 도구 2회(이 Evidence 디렉터리)뿐이다.
`Edit` 대상은 전부 `docs/PHASE-3-TRANSCRIPTION-SMOKE-TEST.md` 한 파일이다.
소스 · 설정 · 의존성 · 테스트 · 다른 문서에 대한 쓰기 작업은 이 Run에 없었다.

> 참고: 이 Run이 시작될 때 작업 트리에는 **이 Task와 무관한 선행 변경**이 이미 있었다
> (`src-tauri/**`, 다른 `docs/*.md` 등이 `M` 상태였다). 그것들은 이 Run이 만든 것이 아니다.

## 같은 오해를 만드는 서술이 남아 있지 않은가 (P5-AC1)

## P5-AC3 — 무효로 만들지 않는 것이 문서에 적혀 있다

`## [정정 2026-09-07]` 블록의 `### 이 정정이 무효로 만들지 않는 것` 소절:

- `ADR-0003 §16.1`의 -25.8 dBFS는 **전사 결과가 아니라 레벨 실측값**이므로 유효하다.
- §부록2의 P8 증폭 실험이 목표로 삼은 것은 **레벨(dBFS)** 이지 '성공한 전사'가 아니므로
  실험 설계가 그대로 선다.
- 틀린 것은 "그 파일은 전사가 성공했다"는 서술 하나다.
